Dashboard Name: MAZI FRAUD AI DASHBOARD
Purpose: Provides real‑time monitoring and detection of fraudulent transactions in financial systems. It enhances security, compliance, and trust.

Features
User Transactions: Displays daily totals, transaction volume, and trend graphs.

Fraud Detection Overview: KPIs for suspicious activities, high‑risk alerts, and confirmed fraud cases.

Fraud Detection Logic: Anomaly detection, behavioral analysis, device fingerprinting, and ML model status.

Alerts & Warnings: Real‑time notifications with severity levels and frozen accounts.

Suspicious Transaction Card: Shows details of flagged transactions (user, amount, location, risk level).

Global Map Visualization: Highlights fraud hotspots worldwide with blocked and flagged transactions.

Fraud Case Insights: Case IDs, fraud type, investigation status, and financial loss amounts.

Recent Transactions Table: User, amount, location, and fraud status.

System Logs & Updates: Detection rules applied, alerts triggered, database sync status.

Action Buttons: Run Analysis, View Reports, Alert Settings.

Technology Stack
Backend: Python Flask

Frontend: HTML, CSS, JavaScript

Database: MySQL for transactions and fraud cases

Validation & Security
Secure login with admin role

Input validation for transaction data

Compliance with PCI DSS and GDPR

Reports & Logs
Fraud case reports with financial impact

Export options (CSV/PDF)

System logs for audit tracking

Future Enhancements
AI‑driven predictive fraud scoring

Integration with external APIs for global fraud intelligence
